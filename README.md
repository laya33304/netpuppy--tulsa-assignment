# Tulas International School — Homepage Redesign

A modern, animated, responsive redesign of the **Tulas International School (TIS)** homepage, created as part of a frontend development assessment.

The project focuses on transforming the existing school website experience into a cleaner, more engaging and conversion-focused single-page interface while retaining the core TIS identity, content and information architecture.

## 📌 Project Overview

Tulas International School is a CBSE-affiliated co-educational boarding and day school located in Dehradun, Uttarakhand.

The goal of this redesign is to create a modern homepage that communicates the school's academic environment, campus life, sports, facilities and admissions experience through:

- Clean visual hierarchy
- Smooth scrolling
- Scroll-triggered animations
- Interactive UI elements
- Responsive layouts
- Strong calls-to-action
- Modern typography and spacing
- Improved navigation experience

The design is intended to work across desktop, tablet and mobile devices.

The redesign focuses on creating a premium educational website experience while maintaining the identity of Tulas International School.

### Design Principles

- Strong visual hierarchy
- Generous whitespace
- Clear typography
- Consistent spacing
- High-quality imagery
- Minimal but meaningful UI elements

### Animation Principles

Implemented interactions include:

- Hero entrance animations
- Scroll-triggered section reveals
- Hover interactions
- Card transitions
- Animated statistics
- Smooth scrolling
- Scroll progress feedback

---

## 🧩 Standout Features

The redesign includes the following assessment-focused features:

### 1. Scroll-Triggered Reveals

Sections and content elements animate into view as the user scrolls through the page.

This creates a more dynamic storytelling experience without overwhelming the user.

### 2. Scroll Progress Indicator

A visual progress indicator communicates how far the user has progressed through the homepage.

### 3. Interactive Hover Effects

Cards, buttons and navigation elements provide visual feedback through subtle transitions and movement.

### 4. Smooth Section Navigation

Navigation links use section anchors to provide smooth movement between major homepage sections.
